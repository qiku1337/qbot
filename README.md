Tibia 7.4 / 8.0 Bot (AutoIt)

A lightweight bot for Tibia 7.4 / 8.0, written in AutoIt, focused on basic automation using memory reading and mouse control.

Features

Auto Heal – automatic HP-based healing

UH Support – uses Ultimate Healing runes when thresholds are met

Aim / Target Assist – assists with targeting during combat

ReadMemory – reads client memory for HP, mana, and status values

Mouse Movement – performs in-game actions via simulated mouse input

Notes

Designed for Tibia otclients (7.4 / 8.0)

No packet injection

archival project
